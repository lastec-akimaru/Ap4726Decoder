FFmpeg / ffprobe License Notice
===============================

This distribution includes FFmpeg-related binaries based on FFmpeg version 4.4.2.

Included binaries
-----------------
This distribution includes:

- ffmpeg
- ffprobe

Included shared libraries
-------------------------
This distribution also includes the following FFmpeg-related shared libraries:

- libavutil.so.56
- libavcodec.so.58
- libavformat.so.58
- libavdevice.so.58
- libavfilter.so.7
- libswscale.so.5
- libswresample.so.3

The included binaries and shared libraries were built with the following configuration:

  --disable-gpl
  --disable-nonfree
  --disable-debug
  --enable-shared
  --enable-gnutls

Based on the above build configuration, these binaries and shared libraries were built
without GPL-only components and without nonfree components.
